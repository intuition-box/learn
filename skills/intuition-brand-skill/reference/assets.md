# Assets

Every file the brand page serves, at https://learn.intuition.box/brand. Each comes as SVG at the address below, and as a PNG at the same address ending in `.png`, rendered at the size given. Prefer the SVG wherever it is accepted.

## Logo

| File | Size | Use |
|---|---|---|
| https://learn.intuition.box/brand/files/intuition-mark-1024x1024.svg | 1024 × 1024 | The mark in Midnight, for light backgrounds |
| https://learn.intuition.box/brand/files/intuition-mark-reversed-1024x1024.svg | 1024 × 1024 | The reversed mark: white, for dark backgrounds, optically corrected for the irradiation illusion |

Both have a transparent background and the clear space built in, so the mark fills about 49% of the canvas height. The mark must stay 16px tall or more: set either file at 33px tall or more. See [logo.md](logo.md).

## Using the files

- Use them as they are: do not recolor, crop into, or redraw them.
- To place the mark at another size, scale the SVG proportionally; its viewBox keeps the clear space.
- For anything not listed here, compose it from the palette, the type and the shapes in this skill rather than editing an existing file.
